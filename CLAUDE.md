# CLAUDE.md

Вся документация для агентов — в [AGENTS.md](AGENTS.md): архитектура, команды
сборки, **инварианты** (обязательны к прочтению до правок кода), карта
хранилища, актуальный техдолг и история аудитов.

Библиотека проверенных аудит-промтов: [docs/audit-prompts.md](docs/audit-prompts.md).

Краткое:
- `npm run typecheck && npm run build` — обязаны быть чистыми перед коммитом.
- Версия поднимается в package.json И src/manifest/manifest.base.json.
- `legacy/` не собирается и не правится — только справка.
- Заметки пользователей — в storage.local, НЕ переносить в sync.
- Любая запись в DOM из подписчика onDomChange — только идемпотентная.
