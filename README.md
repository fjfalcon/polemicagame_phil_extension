# Polemica Notes

Расширение для [polemicagame.com](https://polemicagame.com) с набором функций для игроков
и стримеров: статистика, заметки, удобства в игре, интеграция с OBS и Twitch.

Единая кодовая база на TypeScript, собирается под **Chrome (MV3)** и **Firefox (MV3)**.

Код основан на работах [Phil_Richards](https://t.me/smartestphill).

## Возможности

**Статистика и заметки**
- Статистика игрока при наведении: MMR, винрейт, число игр, «первым убили», винрейт по ролям
  (что показывать — настраивается, есть темы кнопок).
- Заметки на игроков: индикатор «есть заметка», цвет ника, цветные метки со своей палитрой,
  экспорт/импорт бэкапом. Заметка привязана к вечному id игрока и переживает смену ника.
- Окно «Цвета ников»: все записи одним списком, ручное добавление игрока по нику или id.
- Последние игры игрока с пометкой «ПУ» (первым убитый) и пересечения с ним:
  сколько сыграно вместе, кто чаще выигрывал, за какие роли.
- Послеигровая статистика на странице матча: голосования, ночные действия, штрафы.

**На странице профиля**
- Карточка пересечений с этим игроком.
- График MMR: окно последних 120 игр, а максимум и минимум — за всю историю.

**В игре**
- Автопринятие игры, скип стартовых экранов, отключение случайных кликов по веб-камере.
- Быстрая пауза, «подсмотреть роли» удержанием клавиши, подмена/сброс/скрытие роли —
  на переназначаемых клавишах.
- Авто-скрытие своей роли и авто-переключение по фазе день/ночь.
- Переворот камеры игрока; локальный мьют и скрытие камеры — помнятся между
  играми и вкладками, пока не снимешь.
- Кнопка «⋯» сворачивает весь ряд кнопок на плитках (есть и переключатель в
  попапе, вкладка «Иконки») — для тех, кому кнопки мешают.
- Метка «видео оборвалось» на мёртвой плитке и кнопка «Обновить камеры».
- Сворачивание длинных ников; клик по нику разворачивает плитку.
- F5 обновляет страницу (а не открывает настройки игры).
- Возврат в поиск после игры и удержание очереди: подсказки по очереди, авто-переочередь.

**Мой вечер**
- Трекер игровой сессии: серия, ±MMR за вечер, игры и роли. Новая сессия начинается с нуля
  (граница суток — 04:00 или ручной сброс).

**Для стримеров**
- OBS: переключение сцен и авто день/ночь, плавающая панель, автозапись по началу игры,
  клипы по хоткею.
- Панель Twitch-чата поверх игры, с историей, переживающей перезагрузку страницы.
- У всех плавающих окон настраивается фон, заголовок, шрифт и режим «сквозь клики».

**Прочее**
- Уведомление о новой версии (проверка релизов на GitHub).
- Экспорт лога для разбора жалоб (при желании — полный лог кадров сокета комнаты).
- Настройки сгруппированы по вкладкам (Игра · Стата · Роли · Стрим · Ещё).

## Установка (готовые сборки)

Скачай архив из [последнего релиза](https://github.com/fjfalcon/polemicagame_phil_extension/releases/latest):

- **Firefox** — `polemica-notes-firefox-<версия>.xpi`: перетащить файл в окно браузера
  (или `about:addons` → шестерёнка → «Установить дополнение из файла»).
  Файл подписан в Mozilla, поэтому ставится **постоянно**: переживает перезапуск браузера,
  настройки и заметки не стираются. В каталоге AMO дополнение не публикуется —
  распространяется только через релизы этого репозитория.
  Старый путь (`polemica-notes-firefox-<версия>.zip` → `about:debugging#/runtime/this-firefox`
  → «Загрузить временное дополнение») остаётся для отладки, но такая установка слетает
  при закрытии Firefox **вместе со всеми данными расширения**.
- **Chrome / Яндекс.Браузер / Opera / Edge — из Chrome Web Store** (рекомендуется):
  <https://chromewebstore.google.com/detail/haacghfiifkhblmebkmdiifenndpofdo>
  Установка в один клик, **с автообновлением** — новые версии приезжают сами.
  Все Chromium-браузеры умеют ставить расширения из Chrome Web Store по этой
  же ссылке. Расширение опубликовано как *unlisted*: в каталоге и поиске
  стора его нет, ставится только по ссылке.
- **Chrome — из архива** (если нужна версия свежее, чем в сторе) —
  `polemica-notes-chrome-<версия>.zip`: распаковать → открыть `chrome://extensions`
  → включить «Режим разработчика» → «Загрузить распакованное» → выбрать папку.
  Распаковывай всегда в **одну и ту же папку** с заменой файлов: ID распакованного расширения
  Chrome считает от пути, и новая папка для него — другое расширение с чистыми настройками.
- **Яндекс.Браузер** — тот же chrome-архив, адрес страницы расширений — `browser://extensions`,
  дальше шаги те же. Проверено 28.07.2026 на ЯБ 26.4.3 (Chromium 146): ставится и работает.
  Учти: `--load-extension` из командной строки в Chromium 146 отключён, так что автоматические
  прогоны через этот флаг ничего не покажут — только ручная установка.
- **Opera / Edge / Brave / Vivaldi** — тот же chrome-архив; страница расширений
  `opera://extensions`, `edge://extensions` и т.д.

> **Переезжаешь на версию из стора или на подписанный `.xpi`?** Сначала «Ещё» → «Экспорт»
> (бэкап настроек и заметок), потом установка, потом «Импорт». Для браузера это
> разные установки с разными ID, данные сами не перейдут — но это в последний раз:
> дальше обновления приходят поверх, ничего не теряя.

## Сборка

```bash
npm install
npm run build           # собирает dist/chrome и dist/firefox
npm run build:chrome    # только Chrome
npm run build:firefox   # только Firefox
npm run typecheck       # tsc --noEmit
npm test                # вся офлайн-сюита: unit + инварианты (~1300 тестов)
npm run test:contract   # контракт с ЖИВЫМ сайтом (сеть, гоняется по требованию)
npm run lint:ext:firefox  # web-ext lint
```

Релиз собирается через гейт — он же и проверяет:

```bash
npm run release:assets  # typecheck + вся офлайн-сюита + lint + сборка + подпись XPI
npm run release:check   # сверка хэшей артефактов со штампом сборки
```

Артефакты:
- `dist/chrome/` — распаковать в `chrome://extensions` → «Загрузить распакованное».
- `dist/firefox/` — `about:debugging` → «Загрузить временное дополнение» → выбрать `manifest.json`.
  Для публикации нужна подпись: `npx web-ext sign -s dist/firefox` (через AMO).
- Запуск Firefox для разработки: `npm run dev:firefox`.

### Ключевые принципы
- **Кросс-браузерность**: весь код работает через `browser.*` (polyfill). Различия Chrome/Firefox
  только в манифесте (`service_worker` vs `background.scripts`, `browser_specific_settings.gecko`).
- **Фичи** реализуют интерфейс `Feature` (`enable/disable/update`). `FeatureManager` включает/выключает
  их по настройкам — без перезагрузки страницы. `disable()` обязан снимать все слушатели/observers.
- **Одна запись за раз**: заметки и палитра пишутся координатором в background и НАМЕРЕНИЕМ
  («поставь ключ», «добавь цвет»), а не снимком. Запись элемента storage — это замена целиком,
  и вкладка со снимком затирает правку соседней. Обходных путей ровно два, оба под инвариантом:
  фолбэк осиротевшей вкладки и импорт бэкапа из попапа.
- **Настройки** — единый источник правды (`core/settings`). Пароль OBS хранится в `storage.local`
  (не уходит в облачную синхронизацию), заметки — тоже.
- **Селекторы сайта** — в реестре `core/selectors.ts`. Честно: редизайн сайта трогает до трёх
  мест — реестр, `static/notes.css` и CSS-блоки внутри фич; полный список — в шапке selectors.ts.
- **Правила проверяются, а не декларируются**: инварианты в `tests/invariants/` разбирают
  синтаксическое дерево исходников и валят сборку на нарушении — от «селектор сайта вне реестра»
  до «новый писатель карты заметок мимо очереди».

Подробности для разработчика (и для агентов) — в [AGENTS.md](AGENTS.md): инварианты,
карта хранилища, история аудитов.

## Что изменено относительно прежней версии (`legacy/`)
- TypeScript + сборка (tsup), две цели из одного кода.
- `chrome.*` → `browser.*` (polyfill) — работает в Firefox.
- Удалён `chrome.scripting.executeScript` из popup (длина ников — через сообщение в content).
- Один `content.js` вместо 11 скриптов; один общий `MutationObserver` и один keyboard-роутер.
- Фиксы: `content_scripts.matches` покрывает `www.`; убран неиспользуемый `externally_connectable`;
  пароль OBS — в `storage.local`; нативный `window.confirm` больше не переопределяется.
- Удалён мёртвый код (`content-notes2.js`, `module-manager.js`, `*.py`, `head.hex`).

## Режим поворота камер

Порт пользовательского userscript (сейчас живёт внутри `player-notes` и `content/camera-flip.ts`)
[«Rotate Mafia Game Videos»](https://github.com/fjfalcon/mafia_online_javascripts/blob/main/polemicagame.js)
(fjfalcon). В Firefox видео игроков иногда отображается перевёрнутым; при включённом
тумблере «Режим поворота камер» клик по игроку переворачивает его камеру на 180°
(зеркально, через canvas-оверлей), повторный клик возвращает оригинал. Исходник
userscript сохранён в `legacy/userscript-camera.js`.

## Диагностика

Расширение завязано на разметку сайта (реестр селекторов — `src/core/selectors.ts`).
Если после редизайна polemicagame.com что-то перестало работать:

1. Открой консоль DevTools на странице игры.
2. Включи подробные логи: `localStorage.setItem('polemica:loglevel','debug')` и обнови страницу.
3. Выполни `polemicaDiag()` — покажет версию и сколько элементов матчит каждый селектор
   (поле `missing` — селекторы, которые ничего не нашли). По нему видно, что чинить в `selectors.ts`.

Если что-то повело себя странно у пользователя — попроси файл лога: «Ещё» → «Скачать лог».
В нём версия, браузер, включённые фичи и последние события; ники и секреты в файл не пишутся.
Для разбора протокола комнаты есть отдельный тумблер «полный лог сокета» — он хранится
отдельно и по умолчанию выключен.
