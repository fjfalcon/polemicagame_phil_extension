Кнопка «В поиск» после игрыпосле конца игры (и у зрителя/умершего) — одна кнопка: выйти из завершённой игры и снова нажать «Играть», без модалок сайта. Работает только по вашему клику
— пропускать «Покинуть лобби»подтверждать модалку выхода из игры автоматически. Выключите — расширение остановится на модалке и продолжит после вашего подтверждения
Кнопка «Кто в очереди»на странице поиска: на секунду заходит в самую пустую очередь, показывает состав и выходит. Нужна Pro-подписка, иначе только счётчики
Смотреть сразу при открытиибез нажатия кнопки, один раз на открытие страницы поиска (и при включении фичи). В занятую очередь автопросмотр не заходит — только покажет счётчики

Полный лог общения с серверомзаписывает игровые сообщения комнаты целиком — нужен, когда обычного лога не хватает. Камеры и звук не пишутся
Полный лог
В этом файле — вся переписка с сервером за игру, включая роли и ночные ходы. Включай на время разбора и отправляй файл только тому, кому доверяешь. Ключи сессии из него вырезаются, запись хранится на твоём компьютере сутки.
